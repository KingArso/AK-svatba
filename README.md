# Alexandra & Kryštof

Svatební web · 5. června 2027 · Trojanův mlýn.
HTML, CSS a JavaScript, přihlášky přes Formspree, hosting na GitHub Pages.

## Vývoj

Node.js 22+, bez instalace závislostí.

```sh
npm run dev      # lokální web na http://localhost:5173
npm run check    # kontrola JavaScriptu
npm run build    # sestavení do dist/
npm run preview  # náhled sestavení
```

Texty upravujte v `index.html`, vzhled v `styles.css` a nastavení svatby a formuláře v `site.config.js`.
Push do `main` spustí automatické nasazení na GitHub Pages.
